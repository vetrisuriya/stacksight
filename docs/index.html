How it works

Three layers. One second.

StackSight never sends your data anywhere. All three detection layers run locally inside your browser.

1

DOM Layer — HTML signals

Scans script sources, link hrefs, meta generator tags, HTML attributes, and PerformanceResourceTiming entries to identify technology fingerprints embedded in the page markup.

2

JavaScript Layer — Global objects

Reads the page's own JS runtime (window.React, window.__NEXT_DATA__, window.jQuery, etc.) — the most reliable signals that can't be faked by CDN caching or proxies.

3

HTTP Layer — Response headers

The background service worker makes a HEAD request to the current URL and captures response headers: Server, X-Powered-By, CF-Cache-Status, security headers, and more.

4

Analysis & Scoring

All three data layers are merged into a single pageData object. Each detector scores its confidence independently. Results render in the popup within 1–2 seconds.
